Sellaids: a multi-vendor e-commerce platform with fast image delivery

How we built and stabilised a multi-vendor marketplace with around 1,000 products, vendor panels, an admin dashboard and a full image migration to the Cloudinary CDN.

The client

Sellaids is a marketplace where multiple vendors list and sell their products, with a catalogue of around 1,000 items. Product photos are central to the buying decision, so images have to load quickly and look right on every device.

The challenge

  • Product images needed a faster, more scalable way to be stored and served.
  • Vendors needed their own panels to manage products, separate from the main admin.
  • Configuration issues between the front end, API and server were causing errors in production.

What we built

  • Vite-based React storefront that loads fast and keeps product cards consistent across the catalogue.
  • Vendor panels where each seller manages their own listings.
  • Admin dashboard for the marketplace owner, with new features added as the business grew.
  • Cloudinary CDN migration: we moved the product image library to Cloudinary for optimised, resized images served from a global CDN.

Fixing the foundations

Alongside new features, we resolved the problems that were hurting reliability: CORS errors between the storefront and the API, environment variable issues in the Vite build, and an Apache reverse proxy configuration (via .htaccess) so the front end and Node.js API run cleanly on the same server.

The result

Sellaids runs on a stable stack with fast-loading product images, consistent product cards and separate tools for vendors and the marketplace owner, ready to grow its catalogue further.
